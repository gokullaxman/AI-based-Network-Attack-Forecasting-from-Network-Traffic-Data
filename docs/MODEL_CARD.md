## 1. Model Details

### 1.1 Model Taxonomy
The system incorporates two distinct model families:
1. **Primary Empirical Forecaster**: `Target_A_Temporal_Attack_Forecaster` (Balanced Logistic Regression & Random Forest).
2. **Kill-Chain Classifier & Forecaster**: `AttackForecasterBiLSTM` (Dual-Head BiLSTM with SHAP Explainer).

### 1.2 Model Specifications
| Specification | Target A Temporal Forecaster | Dual-Head BiLSTM |
| :--- | :--- | :--- |
| **Model Type** | Balanced Logistic Regression (`model.joblib`) | 2-Layer Bidirectional LSTM (`bilstm_weights.pt`) |
| **Input Shape** | $\mathbf{x} \in \mathbb{R}^{120}$ ($10 \text{ epochs} \times 12 \text{ flow metrics}$) | $\mathbf{X} \in \mathbb{R}^{10 \times 12}$ (10 sequence steps) |
| **Target Task** | Binary Attack-Onset Forecasting (Target A) | Multi-Class Current & Next Attack Phase |
| **Target Horizon** | $[t+3, t+7]$ minutes (5-minute window) | Subsequent phase transition in kill-chain |
| **Pre-Condition** | 10m clean history $[t-9, t]$ + 2m clean gap | Sliding active sequence buffer |
| **Training Source** | Authentic CICIDS2017 1-minute epochs ($N=1,117$) | Synthetic multi-stage Gaussian profiles ($N=300$) |
| **Explainability** | Coefficient odds-ratios | SHAP PyTorch `GradientExplainer` |

## 2. Intended Use & Operational Scope

### 2.1 Intended Applications
- **Proactive SOC Alerting**: Generating early-warning threat advisories when abnormal precursor fluctuations appear across 10-minute flow windows.
- **Dynamic Risk Scoring (0–100)**: Assisting security analysts by summarizing anomalous flow density, transition probability, and severity into actionable risk bands (`LOW`, `MEDIUM`, `HIGH`).
- **Explainable Countermeasure Synthesis**: Prioritizing defensive remediations (e.g., rate-limiting specific ports, IP filtering) with explicit feature attribution rationales.

### 2.2 Out-of-Scope & Unsupported Uses
- **Autonomous Host Disconnection**: The system must not be used to autonomously terminate enterprise core infrastructure without human-in-the-loop analyst verification.
- **Zero-Payload Application Security**: The model does not inspect encrypted application-layer payloads (e.g., SQL injection strings inside HTTPS POST bodies).
- **Hard Real-Time Millisecond Blocking**: The temporal forecaster operates on 1-minute discrete epochs. It is an operational forecaster, not a packet wire-rate firewall.

## 3. Training Data & Preprocessing

### 3.1 Target A Training Split
- **Source**: Authentic CICIDS2017 flow logs extracted from Monday, Tuesday, and Wednesday captures.
- **Sample Count**: $N=1,117$ eligible windows (30 positive onset windows, 1,087 negative benign windows).
- **Attack Scenarios**: FTP-Patator, SSH-Patator, DoS Slowloris, DoS Slowhttptest, DoS Hulk, DoS GoldenEye, Heartbleed (9 distinct onsets).
- **Preprocessing**: `StandardScaler` fitted strictly on the $1,117$ training windows (`scaler.n_samples_seen_ = 1117`).

### 3.2 Dual-Head BiLSTM Training Split
- **Source**: Synthetic attack sequence generator (`pipeline/dataset.py`).
- **Sample Count**: 300 synthetic timelines generated by sampling Gaussian noise around stage behavioral profiles.
- **Loss Function**: Combined Cross-Entropy Loss:
  $$\mathcal{L} = \mathcal{L}_{\text{curr}} + \mathcal{L}_{\text{next}}$$

## 5. Ethical Considerations & Operational Safeguards

1. **Truth-in-Advertising Standard**: The system explicitly reports whether a forecast is derived from authentic flow observations or testing simulations.
2. **Readiness Gating**: If fewer than 10 completed epochs are available, the API returns `INSUFFICIENT_HISTORY` without fabricating fallback predictions.
3. **No Unwarranted Device Fingerprinting**: Endpoints with unrecognized service ports are classified neutrally as `Observed L2/L3 Node`.
